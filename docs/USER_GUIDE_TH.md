# คู่มือใช้งาน FPL Decision Lab

- [อ่านคู่มือบนเว็บ](https://sarayutp.github.io/fpl-decision-lab/guide.html)
- [อ่านต้นฉบับฉบับเต็ม 22 หัวข้อ](../dashboard/guide.md)

เปิดเมนู **วิธีใช้งาน** เพื่ออ่านขั้นตอนเริ่มต้น การตรวจทีม XI กัปตัน Transfers,
News & Risk, Planner, A/B, การ์ดสำหรับแชร์, Journal, Players, Squad Lab,
AI Briefing, ความเป็นส่วนตัว การอัปเดตข้อมูล และการแก้ปัญหา พร้อมตัวอย่างสมมติ

หน้าเว็บมีสารบัญ ดาวน์โหลด Markdown และปุ่มพิมพ์/บันทึกเป็น PDF ผ่าน Browser
อ่านได้แม้ข้อมูลทีมโหลดไม่สำเร็จ และอ่านเนื้อหาได้โดยไม่เปิด JavaScript

`dashboard/guide.md` เป็นต้นฉบับเดียวสำหรับหน้าเว็บและไฟล์ดาวน์โหลด
แก้ที่ไฟล์นั้นแล้วรัน `python -m fpl_mvp build-site` ไม่ต้องแก้เนื้อหา HTML ซ้ำ
ไฟล์นี้เป็นดัชนี ไม่ใช่คู่มืออีกชุด และไม่ต้องใช้ OpenAI API key
